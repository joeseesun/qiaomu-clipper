# 图片问答合入统一测试入口

本次集成基于 1.16.2（771ff49）。图片问答来源文件及摘要见 `IMAGE-CHAT-INTEGRATION.json`，源工作区保持原样。实际交付功能与测试由 `test-delivery.json` 管理。

- 引入图片枚举、读取与内存缓存、长图分块、单图选择、图片编号定位、多模态请求编码及其回归测试。
- 更新后台图片读取桥和消息验证，历史记录只保存文字与图片编号，不保存图片字节。
- 保留当前 `extractXhsNote` 解析器，不引入旧分支的平行 `xiaohongshuArticle` 解析器；前者已经包含笔记身份、轮播顺序与图文/视频区分。
- OAuth 请求的图片编码与现有推理强度设置同时保留。未捎带源工作区中其他助手/字幕设置的未完成改动。

合入后 1088 项前端测试和 9 项构建流程测试通过，TypeScript 检查通过。其中图片请求结构覆盖 Chat Completions、Responses、Codex OAuth、Anthropic、Gemini 和 Ollama；问答界面覆盖实际图片字段、指定单图、读取失败、取消和历史不保存图像字节。

这份记录证明集成和自动检查，不声称已经在用户浏览器重载，也不把源线程的 DeepSeek 实测当作本构建的现场验收。交付后在固定目录重载扩展，刷新原网页并重新打开阅读页；AI 对话应出现「图片 N/N」，提问时出现读取进度。不能再把只显示 Markdown 图片链接的旧阅读页作为新包验证。

固定入口：`~/Documents/乔木剪藏测试/extension`。不要在桌面或 Applications 创建新的用户测试入口。
