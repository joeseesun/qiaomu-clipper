# AI 对话设置（1.9.0）

阅读、编辑和 YouTube 学习的 AI 对话标题栏新增 Lucide 设置按钮。设置仅影响 AI 面板，不改变文章或字幕的排版。

- 字体：系统、宋体／衬线、等宽、本机自定义字体。自定义字体不下载字体文件，不可用时回退系统字体。
- 字号：12–28 px，默认 14 px；字体和字号在设置里实时预览，保存后应用到消息和输入框。
- 自定义指令：最多 4,000 字符，可暂停并保留文本；保存后用于下一次提问，包括已有会话的后续提问。已有回复保持原样。
- 恢复默认只修改草稿，需保存才生效；取消或 Escape 丢弃草稿。保存失败保留草稿并显示反馈。
- 偏好保存在扩展本机存储中，所有文章和视频对话共用；其他已打开的面板通过 storage.onChanged 更新。自定义指令会与文章／字幕一起发送到所选模型。
- 内置阅读规则、文章链接及正文始终保留。自定义指令作为额外指令加入，不替换字幕上下文。

## 参考与取舍

阅读本机 Qiaomu Agent 的 `src/settings-tab.ts`：复用外观／行为分组、字体预览、自定义字体回退、额外系统 Prompt 和恢复默认的思路。浏览器扩展没有 Obsidian 字体环境，不加入“跟随 Obsidian”选项，也不枚举系统字体或请求字体权限。

参考官方文档（2026-10-03）：

- [ChatGPT Custom Instructions](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions)：自定义指令可编辑、暂停，并明确设置作用范围。此处明确描述“下一次提问”，避免将生成中的回复或历史文本误解为会重新生成。
- [Claude personalization](https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features)：区分全局指令与项目上下文。此处全局回复偏好与当前文章／文稿分别构建。
- [W3C Resize Text](https://www.w3.org/WAI/WCAG21/Understanding/resize-text)：文本放大应保持内容和功能可用。提供默认字号 200% 的上限、可滚动设置区和换行按钮；这些实现不等同于完整的 WCAG 合规认证。

## 验证

自动测试覆盖无效偏好回退、字体名称处理、Prompt 开关、保存后的字体应用和真实文稿传递、Escape 取消、存储失败。另运行全套测试、TypeScript、native 测试及三个浏览器构建。

真实扩展页面的自动验收仍受本会话浏览器审批限制；本次发布为预发布，不将自动测试等同于已安装 UI 验收。人工验收需在更新后刷新阅读页面，检查浅色／深色、窄面板、28 px 字号、Tab／Escape、取消／保存／恢复默认，以及下一次提问是否遵循指令并继续引用当前字幕。
