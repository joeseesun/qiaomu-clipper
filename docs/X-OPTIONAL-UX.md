# X 完整阅读：按需启用

此设置流程沿用现有设置页、系统字体与明暗主题。面向普通 Chrome 用户，不要求 Python 或命令行知识。入口展示用户目的「X 完整阅读」，底层组件 Grok 只在条件说明和安装阶段出现。

## 行为

- 设置 → 可选功能始终可找到入口，不弹出首次启动强制安装向导。
- 打开说明页不请求外网、不轮询助手、不开始下载。用途、网络、账号与预计下载大小一起呈现；「暂不启用」与开始设置同时可见。
- 点击「检查连接并设置」才检测官方 Grok 下载服务。不发送文章、Cookie 或凭据；10 秒内返回或取消。不把连通性结果称为账号有效或 X 内容已验证。
- 网络不通时不提供立即下载流程，不要求重装已工作的助手。用户仍能关闭窗口继续其他任务。
- 连通后折叠条件说明，按缺失状态展示安装助手、下载组件、官方网页登录和继续原请求。已有组件复用；不在后台自动安装。
- 本机组件状态每次检测，不用同步到其他电脑的一个开关冒充「安装完成」。原有已配置的 X 读取请求保持正常路径。
- 关闭取消当前窗口启动的操作；失败可重试。登录成功后显示完成，避免重复要求登录。

## 证据与边界

使用 68G 无系统 Python、无可访问 Grok 网络的条件验证离线用户体验；连接成功、原文完整性与翻译能力分别验证。下载估算来自固定组件大小及助手包，显示约数。公开发行仍需要签名安装包、有效版本下载地址与商店发布。
