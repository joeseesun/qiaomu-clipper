# 豆包词级字幕验收

## 行为

豆包极速版返回的字/词时间保留到播放器，原文随播放高亮，当前字加细下划线。翻译字幕仍按句显示。没有词级数据或文字与词序不匹配时，保持普通字幕。旧文字稿不自动重新生成。

## 验证边界

- 助手 208 项测试通过：豆包 HTTP 请求、毫秒换算、分块偏移、清洗、JSON 与轮询保留、消息大小分页。服务端为本机模拟响应。
- 浏览器实际播放测试片段，确认暂停在 2.2 秒时高亮“幕”、回退到 0.2 秒时只高亮“豆”、9 秒无字幕、两倍速实际播放。集成后再次验证样式控制与高亮同时生效。
- 截图：build/qa/karaoke/browser.png。测试页面与播放器使用真实产品代码，模型和存储为测试替身。
- 未验收真实豆包上传、返回内容和特定用户视频的音字对齐精度；未实现 Qwen 对齐模型安装。

## 使用

同时更新助手和扩展后，用户主动用豆包生成字幕，打开播放器字幕。已有旧文字稿需要主动重新生成才能获取词级数据，可能产生豆包转写费用。
