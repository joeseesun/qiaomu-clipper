# 英语学习浮卡

模式：Operate / Read。范围：原页与阅读器共用的选词、选句学习浮卡。主要验收目标为 Chrome。

## Direction contract

- THESIS：一眼看清词义，沿单一阅读顺序读完深入讲解。用户明确不需要章节导航；不添加目录、页签或并列内容面板。
- OWN-WORLD：沿用产品中性色与系统字体，以局部明暗纸面和文本层级承载阅读。浅金色仅标识当前学习词。使用原生按钮、details、可见键盘焦点。
- STORY：选文 → 英美发音 → 词性与释义 → 词典例句、词形和上下文 → 深入学习 → 连续的六项教学内容。
- FIRST VIEWPORT：标题栏最小高度 48px；单词与长选文使用不同字号；英美发音并排；词性和释义分行。词典例句、上下文位于深入学习之前。浮卡最大宽度 480px、最大高度 640px，空间不足时缩小并在卡内滚动。
- SIGNATURE：例句原文与译文成对排版，选中词在语境、词典与 AI 例句中一致突出；上下文按一句英文紧跟一句中文逐句配对。六项教学字段保持完整连续，不以缩写、裁切或默认折叠换取整洁。
- MOTION：只使用 160ms 控件状态过渡，尊重减少动态效果；没有入场编排。
- TRUTH：词典仍使用有道。AI 译文标明来源；模型跟随 AI 对话当前保存的选择。原词形、语法、发音、联想记忆和例句能力保留；整句朗读继续明确标注为合成。

## Overview

这是已有产品内的局部组件规范。继承产品的中性界面、系统字体和明暗模式；下面记录浮卡已实现的局部值，不将其提升为全局 token，也不覆盖根目录中属于阅读器媒体工具区的 `DESIGN.md`。

浮卡以选文旁的非模态阅读面板出现。上半部提供词典资料和朗读，下半部沿一条纵向阅读路径呈现模型讲解。词典资料与 AI 生成内容通过来源链接和文字标注区分。

| 次级文字 / 分隔线 | `#60646b` / `#e5e6e8` | `#b9bdc4` / `#414348` |

明确传入的浅色或深色模式优先；未传入时跟随系统。学习词高亮与普通文本选择是不同状态：普通选择使用正文色作底、纸面色作文字，不追加主题强调色。

## Typography

正文使用 `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`，基础字号与行高为 15px / 1.8；音标单独使用 Arial / sans-serif（15px / 1.45）。

| 层级 | 字号 / 字重 / 行高 | 用途 |
| --- | --- | --- |
| 选词 | 30px / 600 / 1.3 | 当前单词或短语；字距 −0.025em |
| 长选文 | 20px / 500 / 1.65 | 超过 48 字符或 6 个空白分隔词时；恢复正常字距 |
| 词典释义 | 16px / 常规 / 1.85 | 与单独一行的 13px 词性形成层级 |
| 章节标题 | 14px / 650 / 1.5 | 六项讲解的连续标题，不形成导航 |
| 讲解正文 | 15px / 常规 / 1.9 | 语境、语法、联想与发音提示 |
| 常规译义 | 17px / 常规 / 1.8 | 讲解首项 |
| 双语例句 | 英文 15px；中文 14px | 原文先、译文后，译文用次级文字色 |
| 来源与说明 | 12–13px | 来源、模型跟随、缓存与状态说明 |

**完整阅读规则。** 排版可以分段和配对，不能概括、改写或截短已解析的教学字段。无法可靠拆分的双语例句保留为完整段落。

## Layout

浮卡定位优先在选文下方、上方或侧方，距选文 10px、距视口边缘至少 8px；宽度取 480px 与视口可用宽度中的较小值，高度不超过 640px 及实际可用空间。标题栏固定在卡内顶部；正文自行滚动，不遮住关闭入口。

正文默认内边距为上 24px、左右及下 28px。常见间距为控件间 8px、词典条目间 16px、主要区域间 24–26px；相邻教学字段用 1px 分隔线与 22px 顶部留白分开。词性、释义和来源各自承担清楚的阅读层级。

宽度不超过 380px 时，正文内边距改为 20px，选词与长选文字号分别为 27px、19px；不超过 280px 时，正文内边距为 16px，英美发音和词形列表改为单列。长词、URL 和长错误可换行；用顺序重排维持完整内容，不增加横向面板。

## Elevation & Depth

内部使用平面纸面、细分隔线和控件底色表达层级。浮卡外壳使用柔和投影（`0 8px 32px #0003`）与页面区分；教学字段不再各套一层卡片或投影。

## Shapes

外壳圆角为 14px，按钮圆角为 8px，学习词标记圆角为 2px。Lucide 线性图标通常为 16px，来源链接图标为 12px；展开提示用 CSS 线条而不是文字字形模拟图标。

## Components

- **发音与词典资料：** 英美发音通常并排。词性和释义分行；词典例句、词形和缺失音标时的逐词音标使用原生 `details`。词典例句显示实际条数，每条英文和中文成对；保留有道来源链接。没有词典音标时，朗读按钮明确显示“朗读（合成）”。
- **上下文：** 非空上下文按一句英文紧跟一句中文逐句配对，沿用词典例句的英文与中文排版；不再把全部英文和全部译文分成两个区块。包括上下文恰好等于选文的情况。首次展开时按需请求同一份完整讲解；请求传入保留原文的分句数组，要求返回等量、同序的完整译文，数量缺失或空项会报错重试。不能用普通译义或语境解释代替，不计入六项教学字段的简洁长度指引。AI 来源在配对内容末尾以小字标注。
- **深入学习：** 六项字段固定依次为“常规译义、放进上下文、语法与用法、拓展例句、这样记住它、发音提示”，成功后全部连续展开。主按钮生成时显示“停止”，成功后降为次级外观。上下文翻译与六项讲解共用一次请求和结果，不拆成独立模型调用。
- **模型跟随：** 浮卡不显示模型选择器，文案为“翻译与讲解跟随 AI 对话模型。”。后台每次生成重读保存的 AI 对话模型；无效选择回退到第一个已启用模型，与 AI 对话一致。无模型时显示设置入口。
- **讲解依据：** 将已取得的英美词典音标一起提供给模型；发音提示以这些依据为准，缺少双方读音依据时不编造近形词发音差异。语法要求区分实际句子的主语、宾语与宾语补足语。提示契约升级后使用新缓存版本，避免继续复用旧讲解。这些约束不能替代模型输出的事实核对。
- **学习词高亮：** 可识别的单词或短语在上下文、词典英文例句及 AI 例句中用同一种标记突出，避免命中词内子串。匹配接受等价直/弯撇号、标准/Unicode 连字符；标记中的文本保留原始字符、大小写和标点。小写选词允许句首大写，`US/us`、`Polish/polish` 等有意义的大小写区别保留。
- **状态与键盘：** 词典、讲解、上下文翻译和音频分别提供状态或错误提示及相应重试方式。按钮使用 160ms 背景色过渡，减少动态效果模式关闭过渡。键盘焦点有 2px 正文色描边与 3px 外偏移；面板打开时进入焦点，Escape 或关闭按钮退出并按现有选文逻辑恢复焦点。
- **无响应连接：** 后台原有 240 秒请求期限之外，浮卡以 250 秒等待上限兜底；停止请求 5 秒仍无确认时也断开失效连接，清除忙碌状态、禁用依赖该连接的请求控件并提示重新划词，拒绝迟到的响应。已有词典资料与独立音频功能保留。正常完成与明确取消会清除等待计时。

## Do's and Don'ts

- **Do** 保留词典释义、词形、双语例句、英美发音、逐词音标，以及六项完整教学内容。
- **Do** 将完整上下文译文紧接原文，明确区分词典内容、AI 译文、AI 教学例句和合成朗读。
- **Do** 保留请求失败、取消、无模型与会话失效的可见状态；来源不足时显示真实限制。
- **Don't** 为本浮卡添加章节导航、目录、页签、模型选择器，或用默认折叠隐藏六项讲解。
- **Don't** 把助记联想写成真实词源，把逐词词典音标写成整句连读转写，或把合成朗读写成真人录音。
- **Don't** 将组件回放、截图或样例响应视为真实扩展安装、实际模型译文质量或用户验收证据。验证记录保存在仓库外的交付目录。
