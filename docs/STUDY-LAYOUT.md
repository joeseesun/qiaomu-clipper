# 目录、视频尺寸与中文翻译（1.10.0）

阅读模式目录支持收起／展开，收起后正文释放约 200 px 的侧栏空间（移动端沿用目录浮层）。编辑模式在现有属性侧栏里增加 Markdown 正文目录，支持 ATX／Setext 标题并跳过代码块；编辑后的目录自动更新，点击定位到对应编辑位置。两种模式分别记住侧栏状态，避免把阅读偏好误套到属性编辑。

YouTube 播放器下方新增视频尺寸滑杆，范围为正文宽度的 35–100%，始终保持 16:9，调整时保留 iframe／video 实例，不刷新或重新播放。尺寸在本机存储中记住；字幕还在加载时也可调整。

字幕文稿工具栏新增「中文翻译」开关：

- 使用 AI 对话中已选择且启用的模型；无已选模型时使用第一个启用模型。缺少配置时显示反馈，不调用未配置的服务。
- 开启后按原始字幕段落翻译成简体中文，译文显示在原文下方，原文、章节和时间戳保留。中文原文由模型保留不变，不另加重复译文。
- 请求按最多 8 个分块、5,500 个源字符分批；超过 3,500 字符的长段落拆成分块并重新合并。模型输出按 ID 严格对应，缺段、重复 ID、未知 ID 或无效 JSON 都报错，不把错误段落贴到其他时间戳。
- 每批最多等待 60 秒。已完成的批次逐步显示；关闭开关会取消正在进行的请求并隐藏译文。再次开启复用本页缓存；失败后重试仅处理未完成的批次。
- 原始字幕通过已配置的模型服务处理；译文仅缓存在当前页面，不写入聊天记录或本机长期存储，也不会自动写入笔记。复制／下载字幕及 AI 文稿上下文仍使用原文。
- 译文使用 textContent 渲染，模型返回的 HTML 不执行。点击译文跳到该段起点；原文仍保留原有逐字定位。

验证包括目录状态加载与用户操作的竞态、目录定位、同一播放器尺寸调整、批次边界和输出匹配、取消与迟到结果、失败重试、中文原文和缺少模型配置。全套测试、类型检查、native 测试及三个浏览器构建须通过。

真实扩展页面自动验收仍受会话审批限制。1.10.0 为预发布；真实播放器、浅深色布局、窄屏／侧栏拖动及所配置模型的实际翻译质量仍需安装后人工验收。GitHub 发布不代表 Chrome 商店版本已更新。
