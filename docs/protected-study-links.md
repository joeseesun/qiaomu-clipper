# 视频号与小鹅通回放的转写学习（PR #59 整合版）

本次把视频号路径、小鹅通回放路径及视频在编辑／阅读切换时消失的修复整合到同一个测试版本。用户于 2026-10-10 报告本机 r3 测试通过，并授权将这些修改更新到已有 PR #59。下面保留分阶段验证记录；其中「待用户实测」「未发布」描述的是当时状态。

## 视频号

粘贴分享链接后点击「打开元宝并验证」。插件每三秒检查一次用户明确打开的元宝页面及官方播放页面，取得视频后自动继续生成字幕；不需要再点两次「重新读取」。现有登录状态通常可以复用，过期时在元宝原网站重新登录。

只把当前分享网址交给元宝的链接解析接口，没有发送聊天消息或创建对话的调用。解析后的播放入口限于腾讯视频号官方固定路径，媒体限于已验证的 finder.video.qq.com 路径。原始分享地址作为缓存键；微信和元宝 Cookie 不会导出给助手或识别服务。自动读取三分钟后暂停，连续三次不可用也暂停；保留手动重读入口，离开页面停止检查。

## 小鹅通

按 Claude 交接方案整合：短链接先还原为同一店铺、同一直播回放的正常 H5 地址。登录尚未有效时打开该店铺原网站登录页，登录后自动读取，不需要再次手动重读。原站需要访问密码时仍由原网站处理；插件不读取密码表单或收集登录 Cookie。

读取店铺当前登录状态下的回放列表与课程元数据；扩展自身请求不能使用登录状态时，在已打开的同一店铺 H5 标签里执行第一方请求。只使用店铺 API 返回的回放 HLS 地址，后台通过 yt-dlp 下载、ffmpeg 转换音轨，交给用户已有的识别配置。

当前支持 l_ 类型的已结束直播回放；v_／a_ 普通课程、正在直播、无权限、没有回放及受保护媒体不宣称支持。不使用旧 alive_play 直播流，不绕过商家权限或解密受保护内容。回放列表必须有结束标记；媒体片段缺失立即使下载失败，残留的部分文件不会交给识别流程或作为完整字幕缓存。错误提示不输出签名媒体网址。

## 编辑与阅读

本地文件原有临时文件交接方案保留。在线视频使用独立的临时播放记录：签名媒体只存当前标签的 sessionStorage，持久化文字草稿只存随机引用和播放时间、倍速、音量、静音状态。编辑、返回阅读及预览页刷新重新创建播放器，保留最新编辑后的时间戳字幕，切换不重复识别。

临时记录两小时过期，关闭标签也会失效；过期时保留文字和编辑，提供重新打开原链接的入口。播放地址自身可能提前过期，播放器失败同样显示恢复入口。不会把媒体签名写入学习历史、Markdown 导出或笔记。浏览器拒绝保存播放状态时留在当前可播放页面并提示，避免静默丢失视频。

## r3：重新打开后保留手动编辑（2026-10-09）

用户实测发现「重新打开转写学习」只带原网址，新建页面从原识别缓存生成了一份新草稿，导致原编辑看起来丢失；编辑页也只在操作栏动作时保存，恢复按钮没有同步尚未提交的输入。现在编辑输入自动保存，写入顺序串行，写入成功后才更新内存中的已保存稿；失败时明确提示，后续操作可以重试。恢复入口先等待当前编辑保存完成，再带同一草稿 ID 打开学习页；保存失败则留在原页。

恢复页在等待原站验证时也显示原编辑稿；取到新媒体只恢复播放器、播放时间／倍速／音量，跳过重新识别与原缓存覆盖，继续使用同一份文字、标题、属性、插入笔记。再次粘贴原网址或本版保存的同一回放规范地址，也优先找最新编辑稿。签名仍只在标签临时存储；人工编辑稿不会随两小时播放记录或一天临时预览清理一起删除。兼容旧版已有播放引用且清除了原字幕导出记录的编辑稿。已经从浏览器存储删除或从未保存且关闭的文字，没有依据宣称可以自动找回。

最终类型检查、两种构建及版本／ID 检查通过。前端 114 文件／993 项通过（同上 Windows CRLF 夹具排除），助手仍使用已通过 67 项针对性回归的本轮短域名补丁。生产 Edge 默认和店铺别名两条路径新增覆盖恢复前立即保存、验证等待时保留编辑、刷新自动保存、从学习入口再次打开、存储失败后重试；合成识别调用数保持两次初始任务，不因重新打开增加。本地文件另有 7 项模式与 9 项学习流程检查通过。所有自动浏览器检查均为隔离账号／合成媒体和模拟识别；用户随后于 2026-10-10 另行报告本机测试通过。
