# 小鹅通、视频号分享链接的验证入口

本变更修复“粘贴链接，转写学习”把小鹅通、视频号分享链接误当普通网页的问题，增加原网站验证、重新读取和本地文件入口。它不是小鹅通或视频号的专用下载器，也不保证所有课程都可直接转写。

- 小鹅通：识别 xetslk.com 短链接、xiaoe-tech.com 和 xiaoeknow.com 页面。
- 视频号：识别 weixin.qq.com/sph 分享链接和 channels.weixin.qq.com 页面。公众号、微信登录和无关腾讯网站不归入视频号。
- 支持包含说明文字的分享消息和 Markdown 链接；存在多个不同网址时不自动选择。只把提取的网址传入学习页，丢弃说明和访问密码。
- 原网站输入登录信息、访问密码。扩展没有密码输入框，不读取表单值，不把密码传给助手。
- 只有用户明确打开的原网页标签才可检查。检查只返回页面状态和已就绪播放器所在网址，不返回页面 HTML、Cookie、视频地址或正文。
- 微信专用页、密码页、正在直播、未加载页面都有可重试的提示；不会因此启动下载、ASR 或写入完整字幕缓存。
- 电脑页面已具备有限时长的播放器后，才尝试现有 yt-dlp 读取。若需要浏览器状态，继续使用现有的显式授权流程。下载器不能读取时，保留重试和本地文件入口。
- 修复网站探测返回 unsupported 被误报为 helper-outdated；保留旧助手未知操作错误的升级提示。
- 短链接跳转后的网址用于探测及生成任务的源地址和缓存键，避免探测成功后又下载旧短链接。

## 实际样例检查

2026-10-09，在独立 Edge 浏览器会话中检查用户提供的两个分享链接（不在文档或 PR 中保存课程分享码、访问密码和账号数据）：

| 样例 | 桌面 Edge | 普通移动浏览器模式 |
| --- | --- | --- |
| 小鹅通短链接 | 跳转到 mp.xiaoeknow.com，要求微信扫码/微信内打开；没有 video 或密码输入框 | 前往微信打开小程序；没有 video 或密码输入框 |
| 视频号短链接 | 跳转到 channels.weixin.qq.com，展示扫码前往微信观看；没有 video | 展示前往微信观看；没有 video |

这两个样例不能据此宣称“直接转写成功”。没有使用提供的密码，因为浏览器没有提供密码验证界面。没有伪造微信客户端、绕过登录/访问限制、破解媒体加密或自动录制直播。

## 使用

粘贴分享链接，点击“开始”→“打开原页面”。在原网站完成允许的登录或密码验证后，返回学习页点“重新读取”。电脑网页只显示微信入口时，请导入你已获授权保存的音视频文件。目前没有验证这些分享页的完整自动转写。
