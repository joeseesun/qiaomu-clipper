# 保护分享链接的转写路径（开发中）

本地开发分支已接入视频号的官方播放与直接媒体转写路径。小鹅通已修复小程序分享页到正常网页入口的交接，但用户样例的原网站仍暂停该回放页面访问，尚未取得音轨。用户要求先暂停小鹅通，将视频号做成 Windows 测试版本；本次不发布 PR，等待用户实测。

## 行为与边界

- 分享消息只提取一个唯一网址，不把说明、访问密码带入学习页或历史。
- 小鹅通：原网页标签由当前学习页明确打开，只有这个标签可检查。小程序交接页携带的 H5 地址必须与当前店铺、资源一致，才跳转到网页验证入口。密码和登录信息只在原网站输入，不读取表单值。
- 视频号：明确告知链接将交给腾讯元宝解析，用户点击后打开元宝，在原网站正常登录，再点击重新读取。只发送这条视频号分享链接。
- 元宝返回的播放地址仅允许腾讯视频号官方域名及固定播放路径。临时播放凭证留在官方播放页，不进入学习历史、结果缓存或识别服务。
- 官方播放页返回的文件仅允许 finder.video.qq.com 的已实测媒体路径；原始分享地址作为任务／缓存键，媒体地址用于播放器和助手下载。识别服务仅接收音轨，不接收微信／元宝登录 Cookie。
- 每个学习页仅能使用自己打开的解析与播放标签；检查前后验证导航地址，避免读取其他视频。标签失效、登录失效、媒体过期可重新读取。
- 原网站不能播放、正在直播或缺少授权时，不误报为已经取得完整字幕；只有原有识别流程成功后写结果缓存。助手终止后移除任务文件中的签名媒体地址。
- 保留已有 OpenAI 等识别设置、模型以及本地视频编辑／阅读切换修复。Windows 测试版本仅替换扩展程序文件和助手 asr.py；安装前备份，保留助手中此前的小鹅通下载补丁，不更改配置、模型或 Obsidian 知识库。

## 实际样例验证（2026-10-09）

文档不保存用户分享码、课程访问密码、账号信息、API Key 或临时媒体签名。

| 样例 | 实际结果 |
| --- | --- |
| 视频号 | 匿名元宝解析返回 401；用户正常登录后返回成功。官方播放接口返回成功并播放 110.6 秒视频。新 native 下载与音频转换成功；复用用户现有硅基流动 Qwen3-ASR 配置，实际得到 14 段时间戳字幕，末段结束于 110.6 秒。 |
| 小鹅通 | 短链接携带正常 H5 回放入口。用户正常登录成功，学习中心列出对应课程；直接入口、官方 PC 入口及从学习中心打开同一资源，原站均转到暂停访问页面，再回个人中心。未出现访问密码框或播放器。普通手机浏览器模式也未取得音轨。无法据此宣称已转写成功。 |

视频号真实接口及云端识别分步骤验证；生产扩展另用合成网页、媒体与模拟 Native Messaging 验证完整 UI 路由。没有把模拟结果当作真实转写证据，也没有伪造微信客户端、绕过课程权限、解密受保护媒体或更改商家回放设置。
