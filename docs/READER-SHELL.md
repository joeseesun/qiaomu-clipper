# 统一阅读入口（1.10.1）

此前 `aaa` 在 YouTube 上直接进入 `study=youtube` 以避免等待字幕，却漏接了普通剪藏预览的顶部 bar，显示成了旧阅读器控件。这个差异同时影响阅读／编辑切换、RSS、AI 入口及剪藏草稿流程。

普通阅读预览与 YouTube 学习入口现在共同使用 `mountReaderPreviewShell`：

- 同一 `createClipBar`、控件顺序、Aa 设置节点、自动收起和键盘交互。
- 同一 AI 面板、选中文本提问、对话设置和回答加入草稿流程；字幕区域不再重复提供 AI 按钮。
- 同一编辑草稿 ID、复制／下载内容和剪藏状态。YouTube 入口沿用已选默认／匹配模板、库、路径、属性、RSS 及本地保存配置。
- 字幕异步加载期间，顶部 bar 和播放器保持原实例；数据到达后更新草稿与按钮状态。没有字幕时仍可编辑、复制、下载和剪藏视频页面内容，AI 文稿入口保持禁用，并保留字幕重试。
- 视频尺寸、字幕翻译和字幕复制／下载继续留在正文中的视频／字幕区域，作为该内容类型的附加能力。

验证：共享 bar 结构与 Aa 节点复用、加载期间 RSS 选择、保存完成状态、模板与保存目标、草稿 ID 稳定、字幕到达时复用 bar／chat，以及无字幕回退。实际扩展内部页仍受会话审批限制，需安装后验证完整交互；1.10.1 为预发布，GitHub 发布不代表 Chrome 商店更新。
