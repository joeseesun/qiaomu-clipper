# 播放器字幕与文稿剪藏验收

只使用原来的 `/Users/joe/Documents/乔木剪藏测试/extension`，Chrome 资料「乔木剪藏测试」。更新后重载原扩展，刷新原页，关闭旧学习页再重新打开；无需更换安装目录。

1. 在外语视频中开启播放器字幕：首次默认双语，原文在上、中文在下。准备译文时原文可读；中文字幕等待时不能冒充已完成。
2. 菜单分别选择原文、中文、双语、关闭；原文不调用翻译，模式互换复用译文。原字幕是中文时只显示一份，无需模型。
3. 暂停、缓冲、拖动到远处、倍速、无对白区间、带字幕全屏，核对字幕对应声音及当前时间。播放器来源仅接受匹配 iframe 与 origin 的消息。
4. Transcript 右侧「中文译文」只控制文稿。播放器模式不改变文稿，文稿开关不改变播放器字幕。
5. 剪藏内容默认跟随文稿；主动选择原文、中文、双语后记住选择。复制/下载仍跟随文稿显示。
6. 未完整翻译时请求中文/双语剪藏：显示等待与取消，完成后才能保存；失败、取消、文稿替换或草稿持久化冲突不能保存半成品。

自动化测试使用模拟字幕、时钟和模型结果，验证同步及控制逻辑。真实 YouTube/B 站字幕读取、模型质量和实际带字幕全屏仍需播放验收；生成字幕的精度取决于识别结果的原始时间区间，本功能不编造新的时间戳。
