# 转写学习：没有字幕的视频和音频，也能读、能学

> 1.12.0 引入，设置侧栏的「学习」分组里持续完善。

视频没有字幕、播客只有声音、手里只有一段录音：以前只能听。现在点一下「生成字幕」，几分钟（常常几十秒）后就得到带时间戳的文字稿，并且可以像 YouTube 视频一样进入沉浸学习：搜索、点时间戳回听、翻译、问 AI、写笔记。

## 你能用它做什么

| 场景 | 怎么做 | 得到什么 |
|---|---|---|
| YouTube / B 站视频没有字幕 | 在字幕条里点「生成字幕」 | 字幕边生成边出现，完成后可复制、下载、进入沉浸学习 |
| 小宇宙播客 | 打开节目页，右下角字幕条点「生成字幕」 | 整集文字稿，字幕随播放滚动 |
| 手里只有一个链接 | 设置 →「转写学习」粘贴链接 | YouTube、B 站、小宇宙，以及 Vimeo、X、TikTok、SoundCloud、微博、喜马拉雅等 yt-dlp 能读的网站都可以试，成败取决于网站和登录状态 |
| 本地录音、会议、课程 | 在「转写学习」里选文件 | mp3、m4a、wav、flac、mp4 等；文件只交给本机，不上传 |
| 想听播客但没想好听哪个 | 「推荐播客」里点一个节目 | 弹层列出最近几集，一键进入学习 |

推荐播客：张小珺、42章经、半拿铁、晚点聊、Next Token｜词元之外；Latent Space、Dwarkesh Podcast、No Priors、Training Data、The Cognitive Revolution。最新几集都从各节目公开的 RSS 读取。

学过的内容会列在「最近学习」里，随时回来接着看。

## 在本机生成，还是交给云端

第一次点「生成字幕」时选一次，之后按网站记住，不再重复问。

**本机（推荐）**
- 音频只在这台电脑上处理，处理完即删除，不上传，不花钱。
- 引擎有 Whisper、Qwen3-ASR、faster-whisper，约 1.3–1.7 GB。选了还没安装的，会先写明大小，再下载安装，能看到进度，也能取消；不想要了可以在设置里卸载。
- 已经用 Homebrew 装过的，会直接用。
- 速度参考：Apple M5 Pro 上，41 分钟的中文课程从下载到出完字幕约 1 分钟。

**云端**
- 音频会上传给你选的服务，按它的规则计费；上传前界面会先说明。
- 已用真实 key 试过：豆包语音（极速版）、硅基流动 Qwen3-ASR、智谱 GLM、阶跃星辰、小米 MiMo。41 分钟的课程用豆包约 20 秒出完。
- Groq、OpenAI 按公开接口接入，未实测；也可以填本机上的 OpenAI 兼容识别服务。
- 在设置 →「语音识别」里可以保存多个服务并随时切换。

不会在你没选择云端的情况下，悄悄把音频发给任何服务。

## 识别得更准

字幕生成时，会把这条内容的标题、作者和简介当作背景一起交给识别模型。人名、产品名、术语因此更容易写对。目前对本机 Qwen3-ASR、Whisper 和豆包语音有明显帮助。

## 生成之后：沉浸学习

- 视频或播客与文字稿并排，字幕随播放滚动，当前一行高亮。
- 点任何一行的时间戳，跳回那一句。
- 搜索关键词，快速找到想复习的位置。
- 播客页有播放器、倍速和节目介绍；B 站视频的字幕也能跟着播放走。
- 字幕可以复制、下载 TXT，也可以翻译成中文对照，或基于文稿向 AI 提问。
- 读到想记的地方，按 `N` 写下理解，写进学习日记。

## 设置里的位置

设置侧栏新增「学习」分组，把相关设置放在一起：

1. **转写学习**：粘贴链接、选本地文件、推荐播客、最近学习。
2. **语音识别**：选本机引擎或云端服务，管理已保存的服务。
3. **字幕条与网站**：每个网站单独开关字幕条。
4. **阅读器**
5. **学习笔记**

弹窗右上角「⋯」菜单里也有「转写学习」的入口。

## 需要知道的几点

- **本机助手**：转写依赖一个小助手（下载音频、运行本机引擎）。设置里有一键复制的安装提示，也可以运行 `python3 native/install.py --check` 看缺什么。支持 macOS，也支持 Windows。
- **YouTube 常要求登录状态才允许下载音频**。遇到时会先询问，你同意后才读取浏览器的登录信息。
- **B 站**只给已登录账号提供字幕；装好扩展后请刷新已打开的页面。
- **本地文件**在设置页选好后，会通过扩展自己的数据库暂存给学习页，一小时内未取走即清理，取走后立即删除，全程不离开这台电脑。
- **结果缓存在本机**，同一条内容再次打开不用重新生成。

## 隐私一句话

本机模式：音频不出这台电脑。云端模式：音频只发给你亲自选的那个服务，上传前会提示。详见 [PRIVACY.md](../PRIVACY.md)。
