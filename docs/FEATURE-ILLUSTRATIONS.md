# 乔木剪藏 · 核心功能插画

[返回 README](../README.md#功能巡游)

本图集包含十张同系列功能概念插画：暖白纸张、黑红大字与实体桌面场景。第一张视频阅读封面沿用用户选定的原图，其余九张由内置 imagegen 以其为风格参考生成。

这些图片不是界面截图。界面截图仍保留在 README 的可展开区域；字幕、AI、保存与 RSS 的真实限制以 README 文档为准。

README 使用 JPEG 版本降低加载体积；用户选定的视频阅读封面同时保留原始 PNG。生成提示词、相对路径与质检记录见 [素材清单](assets/features/manifest.json)。

## 1. 一键剪藏，存进 Obsidian

![一键剪藏，存进 Obsidian](assets/features/clip-to-obsidian.jpg)

网页正文与选段保存为 Obsidian Markdown，可先阅读或编辑。

## 2. 舒服阅读，随手划线

![舒服阅读，随手划线](assets/features/reader-highlights.jpg)

调整字体、配色与行距，选段划线，阅读页渲染 Markdown 高亮。

## 3. 属性与 Markdown 并排编辑

![属性与 Markdown 并排编辑](assets/features/markdown-editor.jpg)

标题、标签等属性与 Markdown 正文并排编辑，复制、下载或剪藏。

## 4. 围绕文章与选段问 AI

![围绕文章与选段问 AI](assets/features/ai-chat.jpg)

文章全文或选中段落作为上下文，回答可复制或加入笔记；使用自配模型。

## 5. 视频阅读：把视频变成一本书

![把视频变成一本书](assets/features/video-reading.jpg)

视频与字幕同屏，支持时间戳定位和播放器布局切换。书是阅读体验隐喻。

## 6. 双语字幕与时间戳

![双语字幕与时间戳](assets/features/bilingual-transcripts.jpg)

已有字幕逐段翻译，保留原文、译文与原始时间戳；字幕可用性受视频与平台限制。

## 7. 边看边记，写进今天的日记

![边看边记，写进今天的日记](assets/features/learning-notes.jpg)

手动记录选段与想法，附来源和视频时间，写进今天的日记；需要本地助手及兼容日记配置。

## 8. 三连击：阅读、编辑、直接剪藏

![三连击：阅读、编辑、直接剪藏](assets/features/triple-key.jpg)

AAA 阅读、EEE 编辑、QQQ 剪藏；按键可配置，在输入框内不触发。

## 9. 模板与 AI 解读

![模板与 AI 解读](assets/features/ai-templates.jpg)

模板统一属性和正文，按 URL 或页面数据匹配；AI 提示变量按需生成摘要。

## 10. 剪藏时分享到公开 RSS

![剪藏时分享到公开 RSS](assets/features/rss-sharing.jpg)

剪藏时选择公开投稿到乔木 RSS；默认关闭，需要时再勾选。
