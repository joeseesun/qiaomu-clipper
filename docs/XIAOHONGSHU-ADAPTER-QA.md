# 小红书网页适配试验

日期：2026-10-12。基线：main `9a3d2e1`；工作分支：`codex/xiaohongshu-adapter`。

## 实现范围

- 支持已打开的 `/explore/<noteId>`、`/discovery/item/<noteId>` 详情；保留链接的访问参数。
- 剪藏只读取 ID 匹配的当前笔记，保留标题、作者、正文换行与轮播图；按轮播原始序号排序去重，排除评论、头像和推荐。
- 未加载或仍显示上一条笔记时明确报错，不回退剪藏背景推荐流。
- 区分图文 Live Photo 与视频笔记。视频详情使用现有字幕条，放在正文与评论之间；列表和图文不挂视频工具条。
- 学习页从 MAIN 世界中当前笔记的已加载数据取得含音轨 MP4，以及可用时的独立 AAC 音轨；不导出 Cookie，不访问其他笔记状态。
- 前后端限制 HTTPS、笔记路径、媒体 CDN、端口和重定向；拒绝 DRM、外站媒体以及页面切换后的迟到结果。
- 无法读取时提供返回原页播放、重新读取入口。实际转写依赖本分支的新助手代码。

## 安装测试

测试构建版本为 1.16.1。Chrome 使用 `qiaomu-clipper-1.16.1-chrome-local.zip`，解压后在扩展管理页加载解压目录（更新已加载的本地版时，先禁用旧目录，避免同时启用同 ID 的两份扩展）。安装配套 `qiaomu-clipper-helper-1.16.1.pkg` 后，重新加载扩展并刷新小红书笔记页。商店当前版本不会因合并自动更新。

先检查图文剪藏是否只包含正文图片，再从已打开的视频详情进入学习页，生成字幕。图片目前仍为外链。

原始页面片段、媒体签名地址、转写样本和截图保存在本机临时 QA 目录，没有纳入源码。构建现有的 3 条 webpack 体积提醒未在本次扩大处理。
