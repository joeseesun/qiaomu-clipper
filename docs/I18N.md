# 界面多语言

1.15.7 完整覆盖简体中文、繁体中文、英文、日语、韩语、西班牙语、法语、德语和巴西葡萄牙语。完整覆盖指每条当前界面文字都有译文，并不代表经过母语者审校。

## 维护方式

- 新界面文字先用准确的中文写成 `t('中文原文')`，译文位于 `src/i18n/ui-*.json`。
- 本地助手的固定中文消息及带参数消息位于 `src/i18n/helper-*.json`；原始错误中的路径、模型名、URL 和参数保留。
- `data-i18n` 与网页字幕栏的消息位于 `src/_locales/*/messages.json`；命名占位符的定义与英文一致。
- `npm test` 检查八套译文的覆盖、非空值、重复占位符、链接、HTML 和安装命令。新增文字必须同时补齐全部完整语言。
- 其他语言仍可选择，菜单标注“部分翻译”。缺失消息回退到英文。

## 语言行为

插件设置的语言优先于浏览器语言；系统默认保留语言地区信息，香港和繁体字形使用繁体，巴西葡语使用 `pt_BR`。已打开的媒体网页在刷新后读取新的设置。界面语言和视频原始字幕、ASR 识别语言独立。

发布说明目前提供中文和英文，其余语言显示英文说明。语言菜单里的原生语言名称、服务商与模型名保持原名。
