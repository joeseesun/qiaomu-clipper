# 参与开发 / Contributing

在功能分支修改，提交 PR 到 `main`。保留上游许可证，避免提交个人路径、运行配置、凭证、剪藏正文或生产运维记录。

提交前执行 README 中的测试、类型检查、助手测试和 Chrome 构建。界面修改补充实际扩展截图与复现步骤；涉及本地或 RSS 保存时说明目标、失败重试和兼容行为。使用可公开的测试页面。

Work on a feature branch and open a PR against `main`. Preserve upstream license attribution. Do not commit private paths, credentials, runtime configuration, clipped private content or production operations records. Run the verification commands in README, and include real extension screenshots for UI changes. Use public test pages and document save destinations, retries and compatibility.
