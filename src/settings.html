打包成一个文件，用来备份或换电脑，包括模版、属性、对话历史、划线和笔记草稿。文件里有 API Key，请妥善保管。

Activity

Clipping and saving

Vaults

By default, clipped notes are saved to the currently open vault. You can add vaults here if you want the option to save to different vaults. Vault names must exactly match the name of the Obsidian vault. Press enter to add a vault.
    选一次笔记库文件夹，之后一键保存，不用打开 Obsidian。
    查看安装说明

    Saving

    Choose the default option for saving pages. Alternate options appear in the dropdown menu next to the main button.
    Clipped notes will be saved but will not open as a new tab. Obsidian will still be brought to the foreground.

    Sharing

    Off by default. When on, the share option in the clipper is checked for you, and clips are submitted publicly to the Reader Submissions feed.

    Advanced

    Uses the URI clipping method compatible with Obsidian 1.6.7 or earlier. Note that the length of the content you can clip is limited by your browser and OS. Some pages may fail without any errors.
    Remove any changes you've made to the default template.

    Learning notes

    日记

    Add a note button and the N key to the reading and video pages. Notes are appended to today's daily note in your vault through the local helper.
    When a note has selected text, write it into the diary as a quote. You can also switch it per note in the note card.
    Write the page or video link, and the video time, in the diary entry. You can also switch it per note in the note card.

    Transcribe and study

    字幕与转写

    视频页的字幕条

    On YouTube, add Copy, Download and Study buttons next to the Chapters / Transcript tabs of the transcript panel.
    On a video page, expand YouTube's transcript panel once so the transcript is ready for copying, downloading and study mode. Close it and it stays closed for that video.
    When the transcript opens automatically, hide YouTube's panel in the right column. The transcript bar shows the same lines. A panel you open yourself is never hidden.

    支持的网站

    哪些网站可以「转写学习」。前三个在网站里有字幕条和学习页；其余的粘贴链接后在「转写学习」里打开。成功与否取决于网站本身和登录状态，默认全部打开。

    This only turns sound into subtitles. Chinese translation, chat and AI interpretation use AI models, set up separately. Set up AI models

    语音识别

    视频或音频没有字幕时，用语音识别生成带时间的字幕。本机识别免费、音频不离开这台电脑；云端更快，但音频会上传并按量计费。
    每个网站单独设置
    把标题、作者和简介交给识别当参考。简介里的错别字可能被照抄；用云端时，这些公开信息会随音频一起发送。
    不再每次确认。用云端时音频会直接上传；需要先安装，或要换个模型重新生成时，仍会先问。
